# 文献综述 SOP（吸收自 OpenAI4S literature-review）

**触发**：科研问题需要文献支持（找经典论文/证据综述/方法对比/找空白）
**工具**：`memory/sci_methods.py`（verify_dois / crossref_lookup / search_openalex / expand_citations）
**核心**：**检索先行，再写作**——答案从检索结果构建，不是从记忆构建

---

## 第一步：读懂请求真正要什么

| 请求 | 交付物 |
|------|--------|
| "X 的论文是什么" | 1-2 个特定引用 |
| "X 的证据" | 综述（综合，不是列表） |
| "比较 A 和 B" | 对比 + 建议，不是两个相邻摘要 |
| "哪里有空缺" | 具体空缺，综述只作支撑 |

二词模糊查询 → 按领域专家默认范围选择并明说（"我按人类RCT证据理解，动物文献另说"）
只在答案会真正改变行动时才问澄清问题

## 第二步：检索先行（grounding）

1. 第一动作是文献扫描：`search_openalex` / `crossref_lookup` / `web_search`
2. **一篇真实综述通常有 15+ 个不同原始论文 DOI**——每个主张锚定到确立它的论文；几个综述引用 = 阅读清单，不是综述
3. 问具体论文（"原始""开创性"、具名试验/方法）→ 找后续引用都引用的高被引原始论文，不是综述或新闻报道
4. **即使确定知道也验证**：解析你不确定的 DOI 是 1 秒工具调用；**发出的 DOI 要么解析到声称该内容的真实论文，要么是伪造——5 秒可查**
5. 知识截止后的事件/争议发现 → 检索不是可选

## 第三步：引用图双向扩展

```
首轮命中 → 取 2-3 个最相关 → 各走一步：
  向后（references：论文自己的文献）→ 领域的开创性论文在这里浮现
  向前（cited_by：引用它的论文）→ 近年的扩展/质疑在这里浮现
  （关键词扫描无法可靠找到两者）
```

## 第四步：撤销与零结果

- CrossRef `update-to` 字段标记撤销；高知名度/意外发现 → 数秒检查
- 诚实答案是"没有这样的论文"时：指明主张、说出发生了什么、指向实际证据——不是最接近的引用

## 第五步：综合 = 比较，不是摘要

- "论文列表 + 一句话摘要" = 参考书目。有用层在上面：这个结果复现了、那个没有；这三个效应一致但机制不同；这个方法在 A 场景胜出、B 场景输
- 按主题/问题组织，不按论文
- 对比请求的交付物是权衡 + 建议，不是两个摘要

## 写作标准

- 段落以**你的综合主张**开头，然后引用支撑；不是以引用开头报告它发现了什么
  - ❌ "Chen 2019 报告 40% 降低；Park 2020 报告 35%"
  - ✅ "效应真实但温和，汇总估计在 35-40% (Chen 2019; Park 2020)"
- 诊断法：只读每段第一句；连起来是论证 = 综述；是作者名列表 = 带段落外衣的注记书目
- 证据校准：单一队列发现 = "某组报告X"；三期RCT = 直接陈述；争议区 = 双方 + 诚实的"未解决"
- 说清哪些是里程碑、哪些是新近；预印本标预印本；被推翻/精炼的旧结果要标注

## 关键坑

1. **伪造引用是最高风险**：author/year/journal 都有但没有 DOI → 用 CrossRef 查，不要模式补全
2. **DOI 必须可解析**：`verify_dois` 返回值 `ok=False` = 疑似伪造/typo；`ok=None` = 网络无法验证（不算伪造）
3. **检索走 host/web 通道**：本环境用 `sci_methods` 的 urllib 封装；避免绕过 egress/SSRF
4. **"更多研究需要" = 没找到真正空缺**：具体空缺必须锚定到确立它为空缺的证据
