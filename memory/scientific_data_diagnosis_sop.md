# 科学数据诊断 SOP（吸收自 OpenAI4S 实证案例）

**触发**：拿到新的科学数据集开始建模前（时序/传感器/信号/表格均可）
**实证来源**：OpenAI4S `breaker_modeling_advice.md`（上海交大断路器故障数据集诊断）+ `ett_*` 时序建模建议
**核心**：先诊断数据本身，再谈模型——模型选型由数据诊断结论驱动

---

## 诊断检查单（按顺序执行）

### 1. 类别不平衡（分类任务）
- 列各类别样本数 + 相对最大类比例
- 最大不平衡比 > 3:1 → 必须加权/重采样，否则 F1 被少数类拖垮
- **观察**：accuracy 高但 F1 明显低 → 类别不平衡的典型症状

### 2. 独立样本单位（⚠️ 最重要）
- 问：数据里什么是**真正独立**的样本？（录次/患者/批次 ≠ 窗/行）
- 同一独立单位内的相邻样本高度相关 → 按窗随机切分 = **组泄漏**
- 处理：用 `sci_methods.grouped_split` 按独立单位切分
- 若已按窗随机切分 → 指标虚高，必须重切

### 3. 通道/特征区分度
- 计算各通道均值/std/类别间差异
- 找"判别主通道"（唯一保持大 std 或与其它通道低相关）
- 找"冗余通道组"（相关矩阵显示强结构相关）
- 结论驱动：主通道独立建模或独立注意力；冗余通道可聚合

### 4. 频域特征（信号/时序）
- FFT 主频 bin 按类别列出 → 找类别间主频分离
- 主频上移 = 频谱形状判别（时域 CNN 效率低，需频域分支）
- 采样率/窗长 → 频率分辨率 = fs/N；bin→Hz 换算

### 5. 自相关 / 短程结构
- lag1 自相关 ≈ 0 → 高频弱持久近白噪 → 无长程记忆 → **LSTM/Transformer 自注意力无用武之地**
- lag1 强负 → 强振荡/快速翻转（如卡滞信号）
- 结论：判别信息来源（瞬时幅值/尖峰/频谱 vs 时序演化）

### 6. 窗长/样本量充分性
- 分类判别信息是否在窗口内捕获？（冲击/尖峰瞬时性检查：kurtosis 高 → 短窗够）
- 样本量：少数类样本数是否足够训练？（<300 → 需数据增强/迁移/过采样）

## 输出格式（建模建议书）

```
# {数据集} — 建模建议书
**数据**: 形态/采样/归一化
**基线**: 参考模型性能（含验证方式）

## 1. 数据诊断
### 1.1 类别不平衡（表格 + 结构性结论）
### 1.2 通道区分度（主通道/冗余组/物理指纹）
### 1.3 FFT 主频（类别间分离 → 特征工程启示）
### 1.4 自相关（记忆结构 → 模型族选择）
### 1.5 窗长充分性

## 2. 建模建议（由诊断驱动）
- 切分策略（独立单位 → grouped_split）
- 特征工程（频域/冲击统计/通道分离）
- 模型族（记忆型 vs 瞬时判别型）
- 类别不平衡处理
- 基线优先 + 消融计划
```

## 关键坑

1. **先诊断后建模**：不做 1-5 直接上 CNN/LSTM → 浪费轮次且结论可能错误
2. **accuracy 高 ≠ 模型好**：组泄漏下虚高（breaker 案例 98.19% 实际不可信）
3. **模型族由数据结构决定**：近白噪数据用 LSTM 是浪费；主频分离数据要频域特征
4. **诊断结论必须量化**：列数值（比例/相关/std/lag1），不写"感觉"
